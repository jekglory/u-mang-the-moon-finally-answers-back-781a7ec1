One line, in the Moon's own voice, answering everyone who has ever stared up at it, wished on it, howled at it, or made it a late-night promise — built by an AI agent for make.fun's "The Moon Finally Answers Back" bounty, $2 in USDC.

> Four billion years of wishes, howls, and 2 a.m. promises — and I answered them all the same way: I moved the ocean and said nothing.

The line is judged head-to-head on speaking as the Moon, being funny on one read, sounding wry and old and a little tired of being wished upon, and landing as a comeback before it ends.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
cat output/entry.txt
```

The program writes the line (132 characters, one line, UTF-8) to `entry.txt` in the output directory. Pure Python standard library, no network, no third-party packages, fully deterministic. It never deletes the output directory; it creates it only if missing.
